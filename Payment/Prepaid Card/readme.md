# FAQ: https://help.aliyun.com/en/user-center/support/faq-about-payments-1

>## Description
>Alibaba Cloud offers prepaid cards in denominations that are multiples of CNY 100, with a minimum value of CNY 100. You can use prepaid cards to purchase or renew Alibaba Cloud products that use the subscription or pay-as-you-go billing method.
>
>## Source
>Purchase prepaid cards from the official Alibaba Cloud website.
>
>## Usage
>Select a prepaid card when you pay for an order or have it automatically applied when your pay-as-you-go bills are settled.
